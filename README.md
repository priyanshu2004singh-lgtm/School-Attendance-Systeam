# School Attendance Management System

A digital platform designed to simplify and manage student attendance records efficiently.

## Project Overview
The School Attendance Management System helps teachers and administrators maintain student records and track daily attendance digitally. It reduces paperwork, saves time, and improves accuracy.

## Features
- Student Registration
- Add, Update and Delete Student Records
- Daily Attendance Management
- Present and Absent Tracking
- Student Search Functionality
- Attendance History
- Attendance Reports
- Attendance Percentage Calculation

## Technologies Used
- Java
- MySQL
- JDBC
- HTML
- CSS
- JavaScript

## Project Objective
To replace traditional manual attendance registers with an efficient digital attendance management system.

## Future Enhancements
- Admin and Teacher Login
- Parent Notifications
- Automated Attendance Reports
- Dashboard and Analytics
